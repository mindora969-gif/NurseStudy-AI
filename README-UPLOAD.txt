NurseStudy AI — public folder package

UPLOAD the CONTENTS of this folder to the repository's /public directory.

Files:
- index.html: safe directory landing redirect
- nursestudy-bsc-nursing-library.html: primary Learning Centre route
- nursestudy-bsc-nursing-library-3.html: compatibility alias preserving the historical filename
- anatomy-physiology.html: A&P notes and schematic diagrams
- nursing-procedures.html: safety-focused learning frameworks
- assets/site.css: responsive shared styling
- assets/library.js: Learning Centre quiz
- assets/anatomy.js: A&P quiz and topic search

No changes to root index.html, server.js, package.json, or environment variables are required.
The existing Express static middleware serves this directory at /.
