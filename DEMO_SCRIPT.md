# 2-minute demo script

0:00 — Introduce NurseStudy AI and the nursing-student problem.
0:15 — Show the web experience and say it is a simulated Alexa+ experience.
0:30 — Say: “Create a 7-day Anatomy revision plan.” Use the voice button or type Anatomy.
0:45 — Show the generated plan.
1:00 — Click Generate Quiz and show the MCP-powered result.
1:20 — Click Explain Simply and show the response.
1:35 — Show the MCP request log and briefly explain that the web client calls the self-hosted MCP server.
1:50 — Show the three MCP tools and the GitHub repository.
2:05 — Close with the impact: a voice-first study workflow designed around nursing students.
